Zen-Insta (Alpha v0.1) — Distraction-Free Instagram

Tired of wasting hours doomscrolling Reels? Try Zen-Insta, a lightweight, restricted version of Instagram built to keep your screen time under control.


What’s inside:
* No Reels Tab & No Reels Feed (zero mindless scrolling)
* Posts, Stories, Live & DMs work smoothly as usual
* Single-Reel DM Lock: You can still watch a Reel if someone sends it to you in DMs, without swiping into an endless feed


Built by Studio.NSR-Aditya Ram Natarajan. Install the APK and take back your focus!

Open the project using Android Studio Rabbit and open this Directory.
Export the the application as apk and Install on any platforms to experience.
